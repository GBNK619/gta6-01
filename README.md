Palmera Heat is a top-down 2D open-world crime game set in the sun-soaked streets of Palmera City: steal and drive any car, run a five-job story chain for Marco Vidal, and outrun the Palmera Precinct's wanted system. It is built with vanilla JavaScript and Canvas 2D — no libraries, no build step, no network requests.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 in a desktop browser
```
